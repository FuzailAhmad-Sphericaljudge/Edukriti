# Edukriti

Edukriti is a multilingual, adaptive AI teacher that creates grounded, video-led lessons from uploaded study material or a learner-provided topic.

Project planning begins with the [Phase 1 product scope](docs/phase-1-product-scope.md).

## Canonical prototype journey

Upload or topic → personalization → lesson plan → avatar-led teaching → checkpoint → adaptive re-teaching → final assessment → learning report
