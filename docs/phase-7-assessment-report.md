# Phase 7: final assessment and learning report

Phase 7 completes each lesson with an assessment derived from its teaching plan and a durable report derived from the learner's recorded answers.

## Delivered

- Three questions for 5- and 20-minute lessons; five for 60-minute lessons
- A mix of multiple-choice and meaning-evaluated short answers
- One-question-at-a-time assessment experience with immediate feedback
- Durable, idempotent assessment answer storage
- Calculated score based only on recorded final-assessment attempts
- Strong concepts, weak concepts, misconceptions, revision actions, and recommended next topic
- Completed lesson status and report persistence in D1
- Dashboard links to recent in-progress classrooms and completed reports

## Integrity rules

- Final assessment remains locked until all classroom checkpoints are evaluated.
- A report cannot be created until every assessment question has one valid answer.
- Retried network requests return the original attempt instead of creating duplicates.
- Report generation is idempotent and returns the stored report after completion.
