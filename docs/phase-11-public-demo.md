# Phase 11: Public demo journey

Phase 11 reduces the public demo to one meaningful click and makes generated lessons easy to share across devices.

## Delivered

- Added **Try instant demo** on the dashboard. It creates a five-minute visual Hinglish lesson and opens the AI classroom directly.
- Added visible progress and retry feedback while the demo lesson is prepared.
- Added native mobile sharing with a clipboard fallback on lesson-plan and classroom pages.
- Share URLs omit temporary query parameters and point to the durable stored lesson.
- Preserved the custom-topic and source-upload paths for the complete product demonstration.

## Acceptance checks

- A visitor can open the public URL and enter a working classroom with one click.
- Repeated clicks are blocked while lesson creation is in progress.
- Errors remain visible and include a retry action.
- Shared lesson URLs open from another device without requiring the creator's browser state.
