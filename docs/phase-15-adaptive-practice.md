# Phase 15: Adaptive Practice Mode

Phase 15 turns lesson revision into a responsive practice loop that visibly changes after each answer.

## Delivered

- A dedicated adaptive-practice route for every generated lesson.
- Weak concepts from a completed learning report are practiced first.
- Core, support, and challenge modes react to answer accuracy and streaks.
- Immediate feedback, optional explanations, retries, and a live mastery score.
- Practice entry points from the classroom, revision studio, and learning report.

## Acceptance checks

- A learner can always finish or retry the practice set.
- Wrong answers activate a useful clue instead of blocking progress.
- Correct streaks visibly increase challenge level.
- The final mastery result links directly to the final assessment.
